# 🌟 Neha Sonawane - Professional Software Engineer & Data Analyst Portfolio

A modern, high-performance, responsive portfolio website created for **Neha Sonawane** (MCA Graduate from Savitribai Phule Pune University).

## 🚀 Live Features
- **Job-Winning Recruiter Experience**:
  - Persona switcher (`All-Rounder`, `Java Backend Developer`, `Data Analyst / Python`)
  - Recruiter Quick Actions with pre-filled message prompts
  - Instant **"Copy Email"** with clipboard feedback and toast notifications
- **Interactive Project Showcase**:
  - Filterable by tech stack (*Java & Spring Boot*, *Data Analytics & ML*, *Web & Databases*)
  - Interactive deep-dive modal detailing architecture, metrics, and key achievements
- **Industry Experience Timeline**:
  - Highlighting internships at **Amdox**, **TechOctanet Services**, and **NovaNector Services**
- **Skills Matrix & Proficiencies**:
  - Java, Spring Boot, Python, Power BI, SQL, MySQL, PostgreSQL, Pandas, Scikit-learn, REST APIs
- **Integrated ATS-Friendly Resume Modal**:
  - Embedded clean resume with a **1-click "Print / Save PDF"** feature
- **Aesthetics & Micro-Interactions**:
  - Glassmorphism design system
  - Typewriter dynamic role animation
  - Interactive ambient particle canvas
  - Light & Dark mode toggle with `localStorage` memory

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Create a new repository on GitHub named `portfolio` or `Nehasonawane31.github.io`.
2. Push `index.html`, `style.css`, and `script.js` to the repository.
3. Go to **Settings** > **Pages** > Select `main` branch > Click **Save**.
4. Your portfolio will be live at `https://nehasonawane31.github.io/`!

### 2. Vercel / Netlify
- Drag and drop the `neha-portfolio` folder directly into [netlify.com/drop](https://app.netlify.com/drop) or import from GitHub into [vercel.com](https://vercel.com).
